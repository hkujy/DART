# Stochastic Bimodal DTDTA -- Overleaf project

1. In Overleaf choose **New Project > Upload Project** and select the ZIP.
2. The primary file is `main.tex`. Set compiler to **pdfLaTeX** (Overleaf default).
3. `references.bib` holds the original manuscript's reference list.
4. `figures/` contains the original ten standalone numerical-plot panels embedded in the Word manuscript. The network sketch and its six-path parameter table are rebuilt as editable LaTeX/TikZ.
5. Only the ten equations retained in the working manuscript are typeset; omitted analytical derivations and proofs have **not** been reinstated.

The manuscript remains a **working paper**, not a journal-specific LaTeX template.
